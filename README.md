# Agendamento-de-salas
Sistema voltado para agendamento de salas (Reuniões, Biblioteca, Laboratorio) 

# O que fazer após clonar o repositorio:
- cd Agendamento-de-salas
- git status (verificar se está na branch main ou em outras branchs)
- git checkout "teu nome" (Ex: git checkout Lucca)
- git status (verificar se ha algo pendente)

# Quando for subir o código para o repositorio
- git status (verifica se está na branch correta e se tem alguma pendencia)
- git add . (adicionar tudo na fila do commit)
- git commit -m "minha descrição" (comente apenas as principais alterações)
- git push origin "teu nome" (Ex: git push origin Lucca)
- git status (só por precaução)
